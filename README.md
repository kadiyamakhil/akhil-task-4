# Thiranex Task 4 — Asynchronous JavaScript & RESTful APIs

## Project
Real-time Weather Dashboard.

## Features
- Search weather by city name
- Geocoding API converts city name to latitude/longitude
- Fetch API + async/await
- REST/JSON data processing
- Current temperature
- Feels-like temperature
- Humidity
- Wind speed
- Weather condition and icon
- 7-day forecast
- Celsius/Fahrenheit toggle
- Error handling
- Responsive mobile/tablet/desktop design

## API
This project uses Open-Meteo's public APIs:
- Geocoding API
- Weather Forecast API

No API key is required for the public non-commercial API.

## Run
Open `index.html` in VS Code using Live Server, or open it directly in a modern browser.
